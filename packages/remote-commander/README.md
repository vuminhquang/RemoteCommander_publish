# RemoteCommander

Connect this computer to ChatGPT, Claude or any MCP client:

```
npx remote-commander@latest remote
```

A browser page opens; approve it with the RemoteCommander account you connected in your AI client, and the computer appears there. Without `remote`, the command is a local MCP server over stdio (Claude Desktop, Cursor, VS Code).
